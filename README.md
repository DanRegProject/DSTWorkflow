# DSTWorkflow
SAS based workflow for datamanagement for population register studies at Statistics Denmark.

This repository covers procedures proven very useful for manageing very large and numerous datasets on the servers at Statistics Denmark. 
The folder mastercode include SAS, Stata and R macro libraries. Masterdata is a folder, which in production will include a copy of rawdata prepared for extract to subsequent studies. The folder code herein include a complete generic workflow to copy and manage rawdata.
Eventually the Studytemplate folder is a recommended structure of a study folder, including templates af SAS files to extract study data, as well as Stata files for statistical analysis for a standard cohort exposure - outcome study.

All methods and files are available for use, but under own responsibility.
